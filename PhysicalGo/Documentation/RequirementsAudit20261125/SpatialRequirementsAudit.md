## Highest-value changes

1. **Replace unsubstantiated one-pixel dark-fit precision with a cell-scaled adequacy policy.** Exact frame1762 has ECC residual median0.3033 px/p951.0340 px,352 valid tracks and19 per outer edge; it failed solely because p95 exceeded1 px. Minimum local spacing31.6916 px means1 px≈.0316 cell. The neighboring frame's H passes current1762 pixels at p95≈.382 px, establishing proposal sensitivity, not that the board became unusable. The active repair considers median≤min(1 px,.025 cell) and p95≤min(2 px,.05 cell), giving .7923/1.5846 px here. This is a justified candidate to test, not a mathematical error bound or a declaration that all motion is harmless. S01–06.
2. **Correct a drifting held dot instead of faulting at the same boundary used to accept it.** Acquisition and hold both use .20 cell. A settled estimate near.20 can cross due to noise; hold currently throws rather than invoking its existing bounded correction loop. Separate initial accuracy, tolerated stationary jitter and a correction trigger. Keep immediate interruption for unknown target, hand entry, invalid geometry or unsafe motion. S15–16.
3. **Treat small coherent geometry change as a requalification task.** Frozen-anchor median.5/p951 px, extra edge.5/1 px and native-corner2 px vetoes remain after dark-fit repair. They test different facts. Preserve fixed-anchor drift accounting, but classify coherent motion and perform a bounded dark fresh fit/reacquisition, instead of treating every changed frame as lost calibration. S08–10.
4. **Remove the blanket weak-neighbor veto when independent evidence already uniquely identifies a new stone.** PhysicalAI marks a new stone ambiguous if any expected-empty8-neighbor is uncertain or below.8. PG23's retained metadata attributes130 resets/25.418s to this despite Black confidence.933–1.0. Fit quality scores and vote fractions are not probabilities. Replace this with competing-assignment evidence, supported by outlines, game legality and stone-count consistency; do not blindly lower confidence. S48–58.
5. **Avoid fit-to-fit one-pixel reference-renewal requirements and contradictory jitter thresholds.** Automatic dark references require three fits' corners to agree≤1 px. Native grid tracking ignores up to2 px at1080p while the host invalidates differences>2 px. These are likely recurrence points even when dark admission is repaired. Quantify uncertainty and use a stable fused reference rather than treating every estimate as exact. S09/S14/S33–34.
6. **Turn pose/anchor disagreement into a fresh observation where possible.** Firmware intentionally permits held±6 counts, yet host optical anchor reuse stops at3 counts and startup saved-anchor displacement at[8,5]. These checks correctly forbid pairing an old spot with a new pose; they do not establish that the model is lost. Reobserve current stationary pose/spot, and report a recoverable reason. S20–23.
7. **Replace blanket lighting/coverage confidence with relevant observable evidence.** Native lighting fallback can block on fewer than25% empty points or more than25% uncertain points, and hand paths have several fixed brightness/chroma gates. A densely occupied board or a harmless lighting shift is not necessarily unusable. Grid geometry, object identity, target visibility and hand clearance need separate evidence. S35–38/S41–50.
8. **Do not mistake strict residual limits for complete local visibility.** New owner/root controls found local4 px and32 px image warps can pass both old and proposed dark policies despite fewer valid LK tracks and remaining/ambiguous correspondences. Tightening1 px cannot repair missing evidence. Add targeted missing-support/target-local checks and distinguish this pre-existing gap from the current tolerance change. S04/S73.
9. **Unify margins and commissioning-vs-gameplay policies.** The system contains .20 cell aim, .20 cell native disagreement,5 px error+5 px board margin,±6motorcounts with wider actual lit corridors, and several calibration-only3 px model-agreement constraints. Some are derived from lower-layer behavior; others are conservative engineering defaults. Do not keep independent margins just because older tests contain them, and do not widen one without accounting for the others. S17–27/S61–70.

## What must remain distinct

- **Coordinate identity:** which physical intersection corresponds to O17; periodic-grid aliases and orientation mistakes can be an entire cell despite excellent local-looking fits.
- **Fit residual:** how well observations agree with a newly estimated transform. A1 px fit residual is not1 px board movement.
- **Change from an anchor:** how far current geometry has moved relative to the transform currently controlling pointing. This can often be compensated, but current frozen-anchor proof intentionally does not refit.
- **Pointing accuracy:** whether the measured laser spot is close enough to make the requested intersection unambiguous. Current product goal is.20 cell, not3 px everywhere.
- **Visibility/clearance:** whether real pixels support no relevant hand/occlusion. Stable average brightness or inferred missing grid lines cannot prove an obscured target clear.
- **Physical containment:** where a beam and uncertain motor response could travel. The whole allowed motion corridor matters, especially when motors can move asynchronously; numerical model enclosures are conditional on model validity.
- **Input/provenance integrity:** exact hashes, coordinate serialization checks and finite transforms. A.02 px algebraic identity check can be appropriate even when physical accuracy is several pixels; it verifies two representations of the same sample, not the world.

“Safety-related” does not establish that a particular number is justified. The audit preserves the required function while explicitly questioning engineering constants and failure consequences.

## Spatial error allocation

At frame1762, smallest projected spacing is31.6916 px. The currently permitted native/optical corner disagreement is min(8,.20s)=6.3383 px and final aiming tolerance is.20 cell. Blindly adding another.10 cell uncertainty would consume the entire half-cell separation. The candidate.05 cell fit allocation leaves a nominal.05 cell reserve under that conservative sum. **This is a design budget, not a proof:** p95 is not a bound on every target, errors are correlated, corner disagreement need not equal target-local error, centroid/parallax/model errors also matter, and Euclidean “nearest point” depends on perspective. Prefer measured local uncertainty and explicit wrong-intersection competitors. Do not promise a global guarantee from percentile arithmetic.

For motion containment, retain the **physical wooden perimeter** requested by Dave. Printed-grid subregions are acceptable for geometry evidence, but they must not redefine the user’s hand boundary. Keep detection evidence from outsidewood from vetoing an independently clear interior. A fitted boundary’s uncertainty must be represented, rather than silently declaring its mathematical line physically exact.

Board-only motion can often be represented by a new image-to-board transform when the **camera–laser relationship remains rigid**. Camera/laser stand motion together relative to board also requires verifying the model’s coordinate meaning and fresh optical anchor; a moved laser relative to camera cannot be inferred solely from board-camera geometry. No blanket “camera aligned therefore laser calibration valid” recovery is recommended. The correct fallback may be one or a few fresh optical response measurements, not a full five-plus-nine tour.

## Validation before changing a limit

1. Pin exact stage, units, source and active policy. Record observed value, threshold, confidence/visibility context and intended recovery; do not log only “image rejected.”
2. Replay retained positives with nuisance lighting, shadow, board texture, camera jitter and settled pose variation. Include exact initiating failures where available; later similar images are not substitutes.
3. Separately test wrong intersection/orientation, coherent valid movement, partial-board warp, true obstruction, glare-obscured target, stone ambiguity/captures, motor drift and unsafe corridor. A previously labeled negative must be re-evaluated against the actual product requirement: a harmless2 px coherent transform is not automatically a required rejection just because an old test expected it.
4. Test combined budgets and recovery. A new allowed fit must not create a host/native disagreement loop, exhausted edge clearance, repeated cue, clock reset, or resurrect stale illumination authority. Count false stops, wrong accepted placements, correction moves and elapsed time—not merely unit-test count.
5. Promote changes by independent source review, matched source-pinned regression, then attended physical acceptance. Keep quick rollback and the saved game/model. No threshold should be called “safe” solely because old negative fixtures still pass.

Useful instrumentation: a versioned requirement registry with purpose/category/units/default/evidence/owner; a per-stage rejection histogram including distance-to-threshold; local grid/spot uncertainty; clear “reobserve / refit / re-aim / mechanical check” recovery reasons. The registry should cover parameters in the table, not turn all of them into user-facing knobs.
