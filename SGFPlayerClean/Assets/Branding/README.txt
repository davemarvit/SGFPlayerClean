SGF Player reusable icon artwork

SGF-Player-Icon-Master.png — original generated artwork, 1254 x 1254 pixels,
with transparency. Preserve this file when making future variants.

SGF-Player-Icon-1024.png — 1024 x 1024 PNG export, also with transparency.

Current design: vertical wood grain and slightly taller rectangular Go grid
cells, with a black stone above-left and a white stone below-right.

The source revision and generation prompts are preserved in Design/AppIcon
at the repository root. The app icon size variants are in the adjacent
AppIcons.xcassets catalog. This Branding folder is for reuse and is not
copied into the application bundle.

These are reusable artwork files, not a validated App Store submission package.
